 # 🌐 Frontend — Quiz Management & Assessment Platform

The client-side interface for the Quiz Management & Online Assessment Platform built with **React.js** and **Tailwind CSS**. It provides responsive dashboards and real-time quiz workflows for both Students and Administrators.


## 🎨 Tech Stack & Libraries

* **Framework:** React.js
* **Styling:** Tailwind CSS
* **Routing:** React Router (`react-router-dom`)
* **HTTP Client:** Axios
* **Data Visualization:** Recharts (for analytics & dashboards)
* **Form Handling:** React Hook Form

---

## 🚀 Key Modules & Pages

### 1. Authentication
* **Student Auth:** Register, Login, Logout, Password Recovery.
* **Admin Auth:** Protected login and session management.

### 2. Student Portal
* **Dashboard:** Tracks attempted quizzes, average scores, and recent activity.
* **Quiz Discovery:** Search and filter published quizzes by title, category, difficulty, or duration.
* **Live Quiz System:** Displays live countdown timer, interactive question navigation, and real-time option selection.
* **Results & Reviews:** Instant score display with question-by-question answer reviews and explanations.
* **Leaderboard:** Global and category-wise student rankings.

### 3. Admin Portal
* **Dashboard:** Visual charts for quiz attempts, registrations, and pass/fail ratios.
* **Quiz Management:** Form interface to create, edit, publish/unpublish, and delete quizzes.
* **Question Management:** Add multiple-choice questions, options, marks, and explanations.
* **User Management:** View registered students and manage account statuses.
