# Online Quiz & Assessment Management System

An interactive web platform built for conducting online quizzes, tracking student performance, and providing real-time analytics for admins.

## Key Features
- **Role-Based Access Control**: Separate flows for Students and Administrators.
- **Authentication**: JWT-based session security with bcrypt password encryption.
- **Quiz Engine**: Admin quiz creation, question management, and auto-graded student attempts with custom timers.
- **Analytics & Leaderboard**: Instant score evaluation, attempt history, and global/category leaderboards.

## Tech Stack
- **Backend**: Node.js, Express.js, MongoDB (Mongoose), JWT, BcryptJS
- **Tools**: VS Code, PowerShell
